# Intel® AI for Enterprise RAG Docsum Microservice

Part of the Intel® AI for Enterprise RAG ecosystem.

## 🔍 Overview

The Intel® AI for Enterprise RAG Docsum microservice is responsible for scheduling summarization pipelines for the documents.

## 🔗 Related Components

This service integrates with other Intel® AI for Enterprise RAG components:
- Intel AI for Enterprise RAG Text Extractor, Text Compression and Text Splitter load the input data and prepare it before summarization.
- Intel AI for Enterprise RAG LLM Microservice is responsible for connecting to VLLM model server to run the inference on LMM model.
