# Intel® Chatbot Toolkit Docsum Microservice

Part of the Intel® Chatbot Toolkit ecosystem.

## 🔍 Overview

The Intel® Chatbot Toolkit Docsum microservice is responsible for scheduling summarization pipelines for the documents.

## 🔗 Related Components

This service integrates with other Intel® Chatbot Toolkit components:
- Intel® Chatbot Toolkit Text Extractor, Text Compression and Text Splitter load the input data and prepare it before summarization.
- Intel® Chatbot Toolkit LLM Microservice is responsible for connecting to VLLM model server to run the inference on LMM model.
