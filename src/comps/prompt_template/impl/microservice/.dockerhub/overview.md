# Intel® AI for Enterprise RAG Prompt Template Service

Part of the Intel® AI for Enterprise RAG ecosystem.

## Overview

The Intel® AI for Enterprise RAG Prompt Template service manages and applies prompt templates for large language model interactions. This microservice enables consistent, configurable, and effective communication with LLMs by providing structured templates that can be dynamically populated with user queries and retrieved context.

## 🔗 Related Components

This service integrates with other Intel® AI for Enterprise RAG components:
- Retriever service provides context to be inserted in templates
- LLM service consumes the rendered templates
