# Intel® Chatbot Toolkit TTS Model Server

Part of the Intel® Chatbot Toolkit ecosystem.

## 🔍 Overview

The Intel® Chatbot Toolkit TTS Embedding Model Server hosts TTS models, providing a scalable and efficient endpoint for generating audio files from text. It serves as the backend for the Intel® Chatbot Toolkit TTS Microservice.

## 🔗 Related Components

This service integrates with other Intel® Chatbot Toolkit components:
- Intel® Chatbot Toolkit TTS Microservice sends requests to this model server to obtain audio files
