# Intel® AI for Enterprise RAG TTS Model Server

Part of the Intel® AI for Enterprise RAG ecosystem.

## 🔍 Overview

The Intel® AI for Enterprise RAG TTS Embedding Model Server hosts TTS models, providing a scalable and efficient endpoint for generating audio files from text. It serves as the backend for the Intel AI for Enterprise RAG TTS Microservice.

## 🔗 Related Components

This service integrates with other Intel® AI for Enterprise RAG components:
- Intel® AI for Enterprise RAG TTS Microservice sends requests to this model server to obtain audio files
