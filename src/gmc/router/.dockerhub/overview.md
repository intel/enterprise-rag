# Intel® Chatbot Toolkit GMC Router Service

Part of the Intel® Chatbot Toolkit ecosystem.

## 🔍 Overview

The GMC Router service provides intelligent message routing and service discovery for the Intel® Chatbot Toolkit microservice ecosystem. This component acts as a communication backbone, enabling robust inter-service messaging and orchestrating request flow between Intel® Chatbot Toolkit microservices.
