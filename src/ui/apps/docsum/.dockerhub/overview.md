# Intel® AI for Enterprise RAG DocSum UI

Part of the Intel® AI for Enterprise RAG ecosystem.

## 🔍 Overview

The Intel® AI for Enterprise RAG DocSum UI offers an intuitive web interface for interacting with the Enterprise RAG system. This front-end application allows users to summarize raw text or text files.

For administrators, the UI provides capabilities to monitor the status of pipeline components, access telemetry dashboards and authentication admin panel.
