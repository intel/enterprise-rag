# Intel® Chatbot Toolkit DocSum UI

Part of the Intel® Chatbot Toolkit ecosystem.

## 🔍 Overview

The Intel® Chatbot Toolkit DocSum UI offers an intuitive web interface for interacting with the Intel® Chatbot Toolkit system. This front-end application allows users to summarize raw text or text files.

For administrators, the UI provides capabilities to monitor the status of pipeline components, access telemetry dashboards and authentication admin panel.
